# Java Calculator Project

## Description
This project is a simple calculator application written in Java. It allows users to perform basic mathematical operations and view past calculations using a history feature.

---

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Absolute Value
- Calculation History

---

## Technologies Used
- Programming Language: Java
- IDE: Eclipse
- Version Control: Git + GitHub

---

## How to Run
1. Open the project in Eclipse
2. Navigate to Main.java
3. Right-click and select "Run As > Java Application"
